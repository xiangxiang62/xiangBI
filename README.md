## ✨ 项目简介

**XiangBI** 是一个前后端分离的智能 BI 平台，支持用户上传数据文件，自动生成图表并提供分析结果。

相比传统 BI 工具，本项目更偏向 **轻量 + 智能分析 + 易用性**，适合个人项目 / 中小型业务场景。

## 🧩 核心功能

- 📊 数据可视化分析（ECharts）
- 📁 Excel 文件上传解析（EasyExcel）
- 🤖 智能分析（AI + 规则）
- 👤 用户系统（登录 / 权限）
- 📌 图表管理
- ⚡ 异步任务（RabbitMQ）
- 🔐 接口文档（Knife4j）

## 🚀 快速启动

### 1️⃣ 克隆项目

```bash
git clone https://github.com/xiangxiang62/xiangBI.git
cd xiangBI
```

---

## ⚙️ 后端启动

```bash
cd XIangBI-backend
mvn spring-boot:run
```

接口文档：

```
http://localhost:8123/doc.html
```

---

## 🎨 前端启动

```bash
cd XiangBI-frontend
npm install
npm run start:dev
```
