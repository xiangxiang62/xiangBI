# ✨ 项目简介

**享 · XiangBI** 是一个 **前后端分离的智能 BI 平台**，支持用户上传数据文件，自动生成图表并提供分析结果。

相比传统 BI 工具，本项目具有以下优势：

- 🚀 更轻量（无需复杂部署）
- 🧠 更智能（AI + 自动分析）
- 🎯 更易用（开箱即用）

适用场景：

- 个人项目
- 数据分析练手
- 中小型业务系统

# 🚀 快速启动

## 1️⃣ 克隆项目

```bash
git clone https://github.com/xiangxiang62/xiangBI.git
cd xiangBI
```

---

## ⚙️ 后端启动

```bash
cd XiangBI-backend
mvn spring-boot:run
```

接口文档：

```
http://localhost:8123/doc.html
```

---

## 🎨 前端启动

```bash
cd XiangBI-frontend
npm install
npm run start:dev
```
